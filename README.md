# 🛒 Fresh Cart E-Commerce

## 📌 Overview

Fresh Cart is a full-stack e-commerce application that allows users to browse products, manage their cart, and place orders. The system is built with a modern frontend using Angular and a robust backend using ASP.NET Core Web API.

---

## ⚙️ Tech Stack

* Angular
* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* JWT Authentication
* Bootstrap / TailwindCSS

---

## 🚀 Features

* User registration and login system
* Product listing with categories and brands
* Shopping cart functionality (add / remove / update items)
* Order placement and tracking
* Protected routes using authentication
* Responsive UI for all devices
* Clean separation between frontend and backend

---

## 🔐 Authentication

* JWT-based authentication
* Secure API endpoints
* Role-based access (User/Admin)

---

## 🧱 Architecture

* Angular Frontend (SPA)
* ASP.NET Core Backend (REST API)
* Repository Pattern
* Service Layer for business logic
* SQL Server database

## 🧪 How to Run

### Backend

1. Update connection string in `appsettings.json`
2. Run migrations
3. Start API using Visual Studio or `dotnet run`

### Frontend

1. Install dependencies:

   ```
   npm install
   ```
2. Run Angular app:

   ```
   ng serve
   ```
